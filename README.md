<i class="fas fa-server"></i> ## About ArchiveServer

ArchiveServer is an application built thanks to the framework Laravel. Its purpose is to manage Archive cabinets for Document storage and the users that can access to them or to a certain documents on each filecabinet in an easy way to configure it through the application itself.

Additional thanks to:

- Laravel 9.X
- Spatie Permissions
- Laravel Auth
- Bootstrap & Admin LTE Templates
